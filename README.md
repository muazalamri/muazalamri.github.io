## 🌐 Website Overview  
This repository hosts the source code for my personal portfolio website (built with Jekyll and GitHub Pages).  
It includes:  
- A responsive landing page presenting my bio, skills & interests  
- A “Projects” section showcasing major work (embedded, ML/DL, web)  
- Blogs or updates (when I publish)  
- Full source: layouts, includes, assets

### 🧩 Key Components  
- `_layouts/`: custom Jekyll layouts for pages  
- `_includes/`: reusable snippets (header, footer, meta tags)  
- `_projects/`: markdown files for each project, used to render project list  
- `assets/`: images, icons, CSS, JS  
- `_site/`: generated site (not meant to be edited manually)  
- `Gemfile` & `Gemfile.lock`: dependencies for Jekyll build  
- `about.markdown`, `index.markdown`: content pages

## 🚀 Getting Started (Local Development)  
1. Clone the repo:  
   ```bash
   git clone https://github.com/muazalamri/muazalamri.github.io.git
   cd muazalamri.github.io

2. Install dependencies (requires Ruby, Bundler):

bundle install


3. Serve locally:

bundle exec jekyll serve


4. Open http://127.0.0.1:4000 in your browser.


5. Make changes (e.g., edit markdown files, assets) → commit → push. GitHub Pages will update automatically.
